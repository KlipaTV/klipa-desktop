Klipa Player 是一款适用于 Windows 的轻量 IPTV 播放器。打开你自己的 M3U 或 M3U8 播放列表、粘贴播放列表 URL，或使用 Xtream 兼容的登录信息登录，即可配合服务商的节目单观看直播频道。

Klipa 只提供播放器，内容由你提供。它没有自己的频道：请只使用你有权使用的播放列表和服务商账号。

功能
• 播放来自 M3U、M3U8 和 Xtream 兼容源的直播频道，多个源可放在同一个资料库中
• 搜索、频道分组、服务商分类和收藏
• 根据服务商的 XMLTV 节目单（EPG）显示当前和下一个节目，节目单直接从服务商获取
• 全屏、键盘快捷键，以及在播放器中切换频道
• 一键回到上次观看的频道；打开应用时不会自动播放任何内容

留在你的电脑上
• 你的源、收藏和节目单缓存都加密保存在你的电脑上
• 无账号、无广告、无遥测、无后台服务
• Klipa Player 启动时不发起任何网络请求。它只连接你添加的播放列表、服务商、节目单和图片地址，并且直接从你的电脑连接：任何内容都不经过 Klipa 服务器

开源
Klipa Player 是采用 GNU LGPL 3.0 或更高版本许可证的自由软件。源代码、媒体引擎（mpv 和 FFmpeg）的构建以及问题跟踪都在 GitHub 上：https://github.com/KlipaTV/klipa-desktop

界面为英文。

在手机或电视上观看？Klipa 也支持 Android 和 Android TV。
