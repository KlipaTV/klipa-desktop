# Contributing

The project is not accepting public contributions yet. Local development must
keep changes focused, formatted, analyzed, and covered by tests.

Never use real IPTV credentials or copy private Klipa repository history,
infrastructure, store automation, internal instructions, or production
configuration into this repository.

Before external contributions open, this file will define DCO sign-off,
review requirements, issue workflow, and contributor support boundaries.
Until then, pull requests from outside the maintainer team may be closed
without review.
